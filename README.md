# tools_manager

DeepSeek Harness的插件，用于管理dsh上的原有工具或第三方插件提供的工具，你可以通过侧边栏上的工具管理页面进行工具的开启和关闭，关闭后的工具不会写入上下文，你可以通过关闭一些用不到的工具来实现不同的用途并且减少输入token的消耗、以及权限控制。此外该插件还提供了重写系统提示词的功能，你可以通过重写系统提示词进一步缩减token的消耗，或者通过系统提示词为其设置人格、以及其他用途。

## 为什么用它

DSH 的标准模式默认一轮要带几十个工具的声明，多数时候用不上。而DSH的极简模式又会导致无法通过其他插件注入额外提示词，无法读取人格，从而丢失你的个性化配置。并且随着你安装其他的插件，插件中带的工具又会增加你每轮的token消耗，你可以通过这个插件关闭用不到的工具，拥有更高的自由度。

## 怎么用

侧边栏点「工具管理」。

开关改完立即对当前所有活着的会话生效，不用重开会话。点一行能展开完整说明。「解释」是让模型用中文讲这个工具做什么，用于服务英文不友好的用户，来回切不再额外请求。搜索框对名字和说明都生效，换成中文解释之后也能按中文搜索。

`其他插件` 表示它不是内置工具；`本机未安装` 是配置里点了名但环境不支持；`不可关闭` 是会话内建、注册表无法摘除的。

默认值：聊天模式只开启简单的终端工具、文件读写工具和网络搜索、网页抓取工具，常规模式默认全开，但是你可以根据你的需求选择关闭某些工具。

## 顺带的两件事


**模式。** 聊天模式可以自定义系统提示词，这段系统提示词会覆盖DSH原有的系统提示词，因此通过这个模式你可以自定义人格，以满足聊天需求，留空就按当前开着的工具生成。常规模式无法编辑系统提示词，系统提示词为DSH原本提示词。

**网络授权。** 聊天模式下，`web_search` / `web_fetch` 和任何 `web_` 开头的工具，调用前都会请求授权，因为这两个工具会读取网页，导致消耗大量token，你可以自行判断是否需要模型读取网页。
